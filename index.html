ABOUT THE PROJECT

Making Route Information Easier to Find

The Smart Jeepney Route Information System is a student project designed to organize public transportation information in one easy-to-browse website.

It provides route examples, destination information, and general passenger tips through a straightforward interface.

Project Features

  • Simple homepage navigation
  • Destination information
  • Routes grouped by district
  • Passenger travel tips
  • Responsive layout for different screens
