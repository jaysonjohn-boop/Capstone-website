ABOUT THE PROJECT

About CDO Jeepney Guide

Learn about the purpose and scope of the Smart Jeepney Route Information System.

Project Purpose

CDO Jeepney Guide is a student website project that organizes selected jeepney route and destination information in Cagayan de Oro City. It is intended to help students, workers, residents, and visitors browse transportation information more easily.

Technologies Used

  • HTML to structure the website pages.
  • CSS to style the layout, colors, navigation, and content cards.
  • Responsive CSS rules to improve the layout on smaller screens.

Project Limitations

This is a front-end information website. It does not provide a database, user accounts, live GPS tracking, real-time traffic updates, online booking, or payment services. Route information should be confirmed with reliable local sources before travel.
